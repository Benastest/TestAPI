# TestAPI
Hiermit will ich testen wie ich auf API Endpunkte zugreifen kann. Damit möchte ich auch test durchführen und lernen wie ich diese am besten mit best practices in meinem Arbeiten integrieren kann.


## Ziel
Das Ziel ist es eine Wetter API für das LF12 Testprojekt zu bekommen und damit arbeiten zu können. Dies möchte ich mit Python umsetzen.

### Folgendes muss erledigt werden:
1. Auf welche API Endpunkte kann ich zugreifen?
2. Wie kann ich auf die API Endpunkte zugreifen?
3. Wie kann ich einen automatisierten Prozess abbilden?
5. Wie soll ich den Prozess gestalten und umsetzen?
6. Wie müssen die Daten gespeichert und verarbeitet werden?
7. Wie sollen die Daten abgerufen und für das Frontend zur verfügung gestellt werden?
8. Wie kann ich Das Reporting abbilden, also mit welchen Tools?
9. Welche Kriterien müssen erfüllt sein das ich das Reportingtool nutzen kann?
10. Wie kann ich meine gespeichert aufbereiteten Daten zum Reporting zur verfügung stellen?
11. Was soll das Reporting abbilden?
12. Wie sollen die Kennzeahlen und Auswahlmöglichkeiten konkret aussehen?
13. Wie und wer kann auf das Reporting zugreifen?


### generelle Fragen zum Projekt:
1. Wie kann ich auf den Server zugreifen und dort dinge bearbeiten?
2. Wie kann ich das Reportingtools als auch meinen Python Script funktionierend hinterlegen?
3. Gibt es dafür anforderungen die ich beachten muss?
4. Wie kann ich den Code von Lea mit meinen kombinieren, das wir nichts doppelt haben?
5. Ist es möglich das der Server den Code von meinem Repository lädt?
